# GitHub Daily Report

AI developer report generated by a Codex desktop scheduled task. It collects practical AI projects, models, papers, developer news, and agent tooling, uses Codex for Chinese enrichment, archives Markdown, and sends HTML through the connected Gmail plugin.

## Scheduled Delivery

The primary automation runs every Monday and Wednesday at `07:00` in `Asia/Shanghai`. The computer must be on and Codex App must be running with the Gmail plugin connected.

The task follows [`docs/codex-automation-runbook.md`](docs/codex-automation-runbook.md). It sends from `rockyyang951225@gmail.com` to:

- `rockyyang951225@gmail.com`
- `zoeyli1997@gmail.com`

It checks sent mail for the exact Beijing-date subject before sending, so repeated runs do not duplicate the report.

## Local Setup

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -e ".[dev]"
.venv/bin/python -m pytest -v
```

Export fixture candidates without OpenRouter or SMTP credentials:

```bash
.venv/bin/python -m github_daily_report collect \
  --config config/sources.yml \
  --reports-dir reports \
  --output /tmp/github-daily-report-candidates.json \
  --use-fixtures
```

Render a validated Codex draft into Markdown and Gmail HTML:

```bash
.venv/bin/python -m github_daily_report render-codex \
  --candidates /tmp/github-daily-report-candidates.json \
  --draft /tmp/github-daily-report-draft.json \
  --output-dir reports \
  --html-output /tmp/github-daily-report.html
```

## Manual GitHub Actions Fallback

GitHub Actions no longer has a scheduled trigger. `workflow_dispatch` remains available as an emergency manual fallback using the legacy OpenRouter and SMTP path.

That manual workflow still expects these repository secrets:

```text
OPENROUTER_API_KEY
OPENROUTER_MODEL
SMTP_HOST
SMTP_PORT
SMTP_USERNAME
SMTP_PASSWORD
MAIL_FROM
MAIL_TO
```

Optional:

```text
OPENROUTER_BASE_URL
```

Recommended model:

```text
OPENROUTER_MODEL=~anthropic/claude-sonnet-latest
```

Each manual fallback run:

1. Installs the Python package.
2. Runs tests.
3. Generates the daily report.
4. Sends the HTML email by SMTP.
5. Uploads the Markdown report as an artifact.
6. Commits `reports/YYYY-MM-DD.md` back to the repository.
