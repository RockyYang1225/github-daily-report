# GitHub Daily Report

Daily AI developer report generated by GitHub Actions. It collects practical AI projects, models, papers, developer news, and agent tooling, summarizes them in Chinese through OpenRouter, archives Markdown, and sends an HTML email through SMTP.

## Local Setup

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -e ".[dev]"
.venv/bin/python -m pytest -v
```

Run a local fixture dry-run without sending email:

```bash
OPENROUTER_API_KEY=dummy \
OPENROUTER_MODEL=~anthropic/claude-sonnet-latest \
github-daily-report dry-run --config config/sources.yml --output-dir reports --use-fixtures
```

## GitHub Secrets

Configure these repository secrets before enabling the scheduled workflow:

```text
OPENROUTER_API_KEY
OPENROUTER_MODEL
SMTP_HOST
SMTP_PORT
SMTP_USERNAME
SMTP_PASSWORD
MAIL_FROM
MAIL_TO
```

Optional:

```text
OPENROUTER_BASE_URL
```

Recommended model:

```text
OPENROUTER_MODEL=~anthropic/claude-sonnet-latest
```

## Workflow

The workflow runs at `0 23 * * *` UTC, which is Beijing morning. It also supports manual runs through `workflow_dispatch`.

Each run:

1. Installs the Python package.
2. Runs tests.
3. Generates the daily report.
4. Sends the HTML email by SMTP.
5. Uploads the Markdown report as an artifact.
6. Commits `reports/YYYY-MM-DD.md` back to the repository.
