# GitHub Daily Report Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a GitHub Actions powered daily AI developer report that collects high-signal items, summarizes them in Chinese through OpenRouter, archives Markdown, and sends HTML email through SMTP.

**Architecture:** Create a small Python CLI with isolated source collectors, shared normalized models, deterministic ranking, OpenRouter summarization, dual Markdown/HTML rendering, and SMTP delivery. The first implementation favors testable boundaries and simple network adapters over exhaustive crawling.

**Tech Stack:** Python 3.11+, Typer, Pydantic, PyYAML, httpx, feedparser, Jinja2, pytest, GitHub Actions.
