- [chopratejas /](https://github.com/chopratejas/headroom) `Python`, `trending:weekly`
  来源：GitHub Trending Weekly
  中文介绍：headroom 是一个 LLM Token 压缩工具，可在工具输出、日志、文件和 RAG 数据块到达 LLM 之前进行智能压缩，实现 60-95% 的 Token 减少，同时保持答案质量不变。提供库、代理和 MCP 服务器三种集成方式。
  值得关注：Token 成本是 LLM 应用规模化的最大障碍之一。60-95% 的压缩率意味着相同预算下可以处理多倍的请求量，或者在相同成本下使用更强的模型。
  建议：立即用 `pip install headroom` 安装，在现有 RAG 管道中的检索结果传入 LLM 之前插入压缩步骤，测量实际 Token 节省量和答案质量变化。MCP 服务器模式特别适合 Claude Desktop 用户。
  <details>
  <summary>查看详细介绍</summary>

  headroom 采用语义压缩算法，识别并保留对 LLM 回答问题最关键的信息，删除冗余内容。三种集成方式：Python 库（直接调用）、HTTP 代理（无侵入式集成，拦截 LLM API 请求）、MCP 服务器（与 Claude 等支持 MCP 的 AI 工具集成）。适合人群：构建 RAG 系统的工程师、需要控制 API 成本的创业团队、处理大量日志分析的 DevOps 工程师。可尝试场景：压缩 GitHub Actions 日志后发给 LLM 分析错误、压缩长文档 RAG 检索结果、压缩工具调用返回值以支持更长的 Agent 对话链。

  </details>
