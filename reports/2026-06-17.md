  来源：Skills and Agent Tools
  中文介绍：Context Mode 是专为 AI 编码 Agent 设计的上下文窗口优化工具，通过沙箱化工具输出将上下文占用减少约 98%，支持 Claude Code、Cursor、Copilot、Codex、Kiro 等 15 个主流平台。
  值得关注：上下文窗口是 AI 编码 Agent 的核心瓶颈，98% 的压缩率意味着 Agent 可以在同等 token 预算下处理更长的代码库和更复杂的任务，直接提升工程效率和降低成本。
  建议：在 Claude Code 或 Cursor 中安装该插件，对比启用前后处理大型代码库时的 token 消耗和响应质量，评估是否适合纳入团队标准工具链。

  <summary>查看详细介绍</summary>

  Context Mode 的核心思路是将工具调用的输出结果进行沙箱隔离和压缩，避免冗余的工具输出占满上下文窗口。适合人群：重度使用 AI 编码 Agent 的工程师、需要控制 API 成本的团队、处理大型单体代码库的开发者。可尝试场景：在大型 monorepo 中让 Agent 执行跨文件重构、长时间运行的调试会话、需要频繁调用外部工具的自动化流水线。支持 MCP 协议，可与现有工具链无缝集成。
