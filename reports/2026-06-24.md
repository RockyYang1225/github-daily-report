  来源：GitHub AI Search
  中文介绍：Graphify 是一款 AI 编码助手技能插件，能将任意代码文件夹、SQL Schema、R 脚本、Shell 脚本、文档、论文、图片或视频转化为可查询的知识图谱，支持 Claude Code、Codex、Cursor、Gemini CLI 等主流工具。
  值得关注：传统 RAG 方案难以捕捉代码间的结构化关系，而知识图谱能将应用代码、数据库 Schema 和基础设施配置整合为统一的语义网络，让 AI 助手真正「理解」整个项目。
  建议：在现有 Claude Code 或 Cursor 工作流中安装 Graphify 技能，对中大型代码仓库运行一次图谱构建，然后尝试跨文件的架构级提问。
  <details>
  <summary>查看详细介绍</summary>

  Graphify 基于 GraphRAG 和 Leiden 社区检测算法，使用 Tree-sitter 解析代码语法树，将代码实体（函数、类、表、接口）及其关系（调用、继承、引用）存储为图结构。查询时可进行语义搜索和图遍历，远比向量检索更精准。适合大型单体应用重构、微服务依赖分析、数据库 Schema 理解等场景，尤其适合需要快速上手陌生代码库的开发者。

  </details>
